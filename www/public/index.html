后台功能

Vue 与 React 两套后台提供一致的页面与能力，差异仅在技术栈和对应的界面组件实现。

Vue 后台模板 Vue 3 · Element Plus

  • 工作台与导航
    动态菜单、菜单搜索、页签和快捷入口，按账号权限控制页面与按钮操作。
  • 系统管理
    用户、部门、角色、菜单和字典管理，支持权限预览与操作审计。
  • 账号与安全
    登录、修改密码、会话管理、个人中心和锁屏，可选 Google Authenticator。
  • 界面偏好与更新
    主题、布局、组件尺寸、页签风格、中英文和应用时区；支持 PWA 更新提示，确认后刷新。

@npora/request

为浏览器、Node.js 和 Worker 提供统一的 HTTP 请求接口。用在线控制台体验流式响应、取消请求、失败重试和认证刷新。

打开控制台 ↗ API 文档 ↗
安装与使用
npm install @npora/request
import { createClient } from '@npora/request/core'

const api = createClient({ baseURL: '/api' })
const user = await api.get('/user')
