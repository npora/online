CONNECT YOUR FRONTEND

确认接口覆盖后再连接模板

示例尚不能驱动完整后台。只有对应 README 的未实现清单已清零，并完成两套模板的接口联调后，再配置模板 .env.development 中的 VITE_API_URL。Node.js 默认端口为 3000，Go 为 8080；保留模板现有 VITE_API_PREFIX=/api，重启开发服务器。局域网访问时使用服务端局域网 IP，并配置后端来源白名单。

Node.js 地址示例（不代表已可完整接入）
