后台功能

Vue 后台模板

  • 工作台与导航
    动态菜单、菜单搜索和页签，按角色控制页面与按钮权限。
  • 系统管理
    用户、部门、角色、菜单和字典管理，支持权限预览与操作审计。
  • 账号安全
    登录、改密和会话管理，可选 Google Authenticator，支持顶栏锁屏。
  • 界面偏好与更新
    切换主题、布局、中英文与应用时区。生产站点使用 PWA 更新提示，新版由用户确认后刷新。
查看 Vue 使用指南 ↗

React 后台模板

  • 工作台与导航
    工作台统计、动态菜单、菜单搜索和页签，沿用 Vue 模板的组件标识与权限约定。
  • 系统管理
    用户、部门、角色、菜单和字典管理，支持操作审计。公开演示使用只读数据。
  • 账号安全
    登录、会话管理、个人中心与顶栏锁屏，可配置 Google Authenticator。
  • 界面偏好与更新
    切换中英文与应用时区。生产构建生成 PWA 更新服务，新版由用户确认后刷新。

快速开始

Vue 和 React 脚手架都提供纯净版，适合接入自己的后端。线上站点提供独立的演示环境。

生成 Vue 项目

使用已发布的 @npora/create-admin 创建纯净版并安装依赖。

npx @npora/create-admin@latest my-admin --yes --install npm
cd my-admin
npm run dev
生成器参数 ↗ Vue SQL 详情与用法 ↗

使用 React 纯净模板

React 的生成器支持待 npm 发布，目前可从源码启动。

git clone https://github.com/npora/admin-template-react.git
cd admin-template-react
npm ci
npm run dev

安装请求库

npm install @npora/request
